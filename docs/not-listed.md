# Not listed (yet)

The board lists apps you can open and judge. A public GitHub repo is the
bar to be *eligible*, but to be *listed* a row also has to be a working app
someone could actually use and review. These public repos were reviewed and
left off, with the reason. Nothing here is permanent; if the reason goes
away, the row can come back.

## Recoverable — a small fix puts these on the board

- **Checklist Tooling** (`clickconstruction/checklisttooling.github.io`) — a
  complete 25 KB single-file app, but GitHub Pages was never turned on for
  it, so there is nothing to open. Enable Pages and it is listable as-is.
- **Plot Coder** (`plot-coder/plotcoder.github.io`) — the custom domain
  `plotcoder.com` fails TLS because the certificate does not match the host.
  Fix the domain (or point the row at the `github.io` URL) and it will at
  least load. It is only 29 lines today, so it also needs to actually be an
  app.

## Not an app

- **Click Plumbing** (`Click-Plumbing/click-plumbing.github.io`) — the
  plumbing company's marketing website (Austin to San Antonio, 24/7
  emergency, 800+ projects). A site, not a tool.
- **Growing Roots** (`Growing-Roots-Project/growingrootsproject.github.io`)
  — a 501(c)(3) charity's site.
- **Cassbees** (`cassbees/cassbees.github.io`) — a beekeeper's
  swarm-collection service page.
- **Signal Shopper** (`signalshopper/signalshopper.github.io`) — a marketing
  page. Its sub-pages are static signal archives, a store, and API docs, and
  `src/` is an unused create-react-app skeleton.

## Dead or unreleased

- **Wire Texas** (`Click-Plumbing/wiretexas`) — a farewell notice: "Wire
  Texas has now merged with Click Plumbing."
- **Pipe Texas** (`pipetexas/pipetexas.github.io`) — an unmodified GitHub
  Pages stub ("This site is open source. Improve this page.").
- **Proposal App** (`Click-Plumbing/proposal-app`) — only a LICENSE and a
  README. The Flask app the README describes was never pushed.

## Fabricated social proof

- **Sync Tooling** (`clickconstruction/synctooling.github.io`) — a demo
  landing page with invented testimonials and made-up statistics ("improved
  our efficiency by at least 25%").
- **Connect Tooling** (`clickconstruction/connecttooling.github.io`) — same:
  fake testimonials ("cut logistics delays by 30%"). On a board whose whole
  premise is that reviews are real and pinned to a commit, these work against
  us until the invented proof is removed.
